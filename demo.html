What a real build needs (notes for the district)

  • Data store: a FERPA-compliant, access-controlled database — not GitHub. GitHub holds the app code; the district controls the student data.
  • Roles: teacher (log + see their students), team (dashboards), admin (everything), parent (their child only, optional).
  • SIS sync: names & schedules from PowerSchool, refreshed nightly.
  • Real voice + AI: on-device speech-to-text, then an LLM (e.g. Claude) to draft the structured entry and a parent-friendly good-news summary. This prototype uses your browser’s built-in speech and a simple keyword tagger to show the flow.
  • Audit log: who viewed/edited each record.
